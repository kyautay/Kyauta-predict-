# Build Kyauta Predict on GitHub1. Create a GitHub account and a new repository named `kyauta-predict`.2. Upload every file and folder in this project to the repository.3. Make sure the default branch is `main`.4. Open the repository's **Actions** tab.5. Select **Build Kyauta Predict APK** and press **Run workflow**.6. When the workflow finishes successfully, open the workflow run and download the artifact named `kyauta-predict-apk`.7. Extract the ZIP and install `app-release.apk` on your Android phone.The workflow uses a hosted Ubuntu runner and Flutter's stable channel. It builds a release APK and stores it as a GitHub Actions artifact.Kyauta PredictStarter Flutter football prediction app with HT/FT, BTTS, Over/Under, 1X2, Correct Score and confidence.
